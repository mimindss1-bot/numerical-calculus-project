# Numerical Calculus: Accuracy, Resolution, and Computational Cost

An English-language mathematical report and executable Jupyter notebook comparing numerical derivatives and integrals, with a synthetic motion application.

## Research question
How do method choice and sampling resolution affect numerical error and sampling cost?

## Read or run
- Open `numerical_calculus.html` for the executed report, including embedded figures. Mathematical typesetting may require Internet access for MathJax.
- Open `numerical_calculus.ipynb` in Jupyter and select **Restart Kernel and Run All Cells**.
- Install dependencies with `python -m pip install -r requirements.txt` in a virtual environment.
- `tested-environment.txt` records the exact environment used for validation; the broader dependency ranges are not a claim that every version was tested.
- From the project directory, `python verify_notebook.py` executes the notebook from a fresh kernel, validates outputs, and regenerates the HTML report. Local Jupyter kernel ports must be permitted.

## Methods and results
Forward and central differences; composite left rectangles and trapezoids; known analytical benchmarks; convergence fits; sampled-value cost; endpoint cancellation; nonsmoothness counterexample; fixed-seed noise experiment; velocity and displacement application.

`results/` contains four figure PNGs, five CSV tables, and a generated convergence summary. All are regenerated by running the notebook. The notebook contains assertions for known values, invalid inputs, reversal of integration bounds, and theoretical bounds.
